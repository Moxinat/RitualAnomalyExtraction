
# **Ritual Extraction** (Hytale ModJam Minigame Submission)

## Description

You enter a distorted horror location from a control room, you must search for ritual objects while avoiding a monster, you must decide whether each location variant is real or fake before completing the ritual to escape in time. 


## How to play (step by step)

1. Download jar and put it into your mods folder
2. Run and join your world
3. Start the game whenever you are ready by issuing `/start` command 
4. Run around the map and find the ritual objects, You only have 10 minutes!
5. One at a time return to the pedestal and place the objects
- Once you find all four, you win!

## Features

- Instance Creation
- Multiple Players
- Custom Entities
- Custom Items
- Custom Map
